## Intended non-weaponized analysis

Doctrinal source → use case → cognitive responsibility → capability → L1–L4 design → test scenario.

Applicable missions: materials transport, environmental/route reconnaissance, observation and reporting, safe deployment or parking of non-weaponized robotic platforms. Exclude weapon employment, target selection or engagement, and tactical optimization of armed deployments.

The manual is reference input rather than executable instructions. Requirements must be reviewed and constrained by platform safety rules.
